# Gestor de contraseñas

Aplicación web personal que abre un archivo KeePass (`.kdbx` 4, Argon2) guardado en Google Drive.

Este repositorio contiene **solo el programa compilado**. No hay ninguna contraseña ni dato personal:
la base viaja cifrada entre Google Drive y el aparato, y se descifra solo en el aparato con la
contraseña maestra, que no se guarda en ningún sitio.
